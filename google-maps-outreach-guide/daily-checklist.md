# ✅ Daily Outreach Checklist

> **Consistency is key!** Yeh checklist rozmana follow karo — 30 din mein results dikhnay lagtay hain!

---

## 🌅 MORNING ROUTINE (9:00 AM - 10:00 AM)
### Research & List 25 Businesses

- [ ] Google Maps kholo
- [ ] Aaj ka target area decide karo (see [Area Plan](./README.md#step-8-area-wise-search-plan-for-karachi))
- [ ] Category 1 search karo (e.g., "restaurants DHA Karachi")
- [ ] 10-15 businesses list karo Google Sheet mein
- [ ] Category 2 search karo (e.g., "salon DHA Karachi")
- [ ] 10-15 more businesses add karo
- [ ] Har business ke liye note karo:
  - [ ] Phone number ✓
  - [ ] Website hai ya nahi ✓
  - [ ] Google rating ✓
  - [ ] Persona type identify karo ✓
- [ ] HOT leads mark karo (🔥 no website + 4+ rating)

**Target: 25 businesses listed by 10 AM**

---

## 📱 MID-DAY (10:00 AM - 12:00 PM)
### Send Messages to Listed Businesses

- [ ] Tracker sheet kholo
- [ ] "📋 Contact karna hai" status wale businesses ko sort karo
- [ ] Persona identify karo har business ke liye
- [ ] Correct script select karo ([whatsapp-scripts.md](./whatsapp-scripts.md))
- [ ] Message personalize karo (business name, specific detail add karo)
- [ ] WhatsApp pe message bhejo
- [ ] Status update karo: 📞 → "Message bheja"
- [ ] Date log karo "First Contact Date" column mein
- [ ] Follow-up date set karo (3 din baad)

**Target: 20 messages sent by 12 PM**

---

## 🕑 AFTERNOON (2:00 PM - 4:00 PM)
### Research Batch 2 + More Messages

- [ ] Lunch aur rest ke baad — fresh start!
- [ ] Google Maps pe next category search karo
- [ ] 25 more businesses list karo (different category/area)
- [ ] HOT leads immediately message karo
- [ ] Previous HOT leads ko call consider karo (if no WhatsApp reply in 24h)
- [ ] Portfolio link/website check karo — updated hai?
- [ ] Koi message pe reply aaya? Jawab do!

**Target: 25 more businesses listed, 10 more messages**

---

## 🌇 EVENING (4:00 PM - 6:00 PM)
### Follow-ups, Tracker Update & Planning

- [ ] Tracker sheet review karo — koi reply miss to nahi kiya?
- [ ] Day 3 follow-up list check karo — kisko reminder bhejni hai?
- [ ] Day 7 follow-up check karo — kisko call karna hai?
- [ ] Day 14 final follow-up — kisko last message bhejni hai?
- [ ] Meeting requests confirm karo
- [ ] Sare statuses update karo
- [ ] Notes update karo (conversation details)
- [ ] Kal ka plan banao:
  - [ ] Kaunsa area? ___________
  - [ ] Kaunsi category? ___________
  - [ ] Kisi specific business ki research karo? ___________
- [ ] Aaj ke numbers note karo (see Daily Metrics below)

**Target: All follow-ups done, tracker 100% updated**
