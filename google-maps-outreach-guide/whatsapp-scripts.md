## 1. First Contact Messages

### 🚀 Persona 1: Startup Sajid (Age 25-35)

**Version A — No Website:**
```
Assalam o Alaikum [Name] bhai/sir! 👋

Main [Your Name] hun, web developer Karachi se.

Maine aapka [Business Name] Google Maps pe dekha — bohat acha concept hai! 🔥

Notice kiya ke website nahi hai — agar ho to:
✅ Customers direct order kar saken
✅ Google search mein aao
✅ JazzCash/EasyPaisa payment accept ho
✅ Brand professional lage

1 hafty mein online kar sakta hun — starting from 30k! 💪

Portfolio: [Your Portfolio Link]

Interested? Reply karein! 🙌
```

**Version B — Outdated Website:**
```
Assalam o Alaikum [Name] bhai! 

Main [Your Name] hun — web developer.

Aapki [Business Name] ki website dekhi — concept acha hai lekin website thori 
upgrade chahti hai:
❌ Mobile pe theek nahi dikhrahi
❌ Speed slow hai
❌ Design outdated lag raha hai

Main isko completely redesign kar sakta hun with modern look + fast speed.

Budget-friendly — starting 35k se. Portfolio: [Link]

Baat karte hain? 📞
```

## 2. Follow-up Messages

**Casual Version:**
```

Bas check karna tha — busy hon to no problem! Jab bhi time ho bata dein.

Interested hain to baat karte hain, nahi hain to bhi koi baat nahi 😊

[Your Name]
```

**Formal Version:**
```
[Name] sahab, assalam o alaikum.

Hope all is well. I had shared a message earlier regarding website development 
for [Business Name].

Just following up — please let me know if you'd like to discuss further, 
or if the timing isn't right.

Happy to assist whenever convenient for you.

[Your Name]
```

## 5. Deal Closing Messages

### 🤝 When They're Almost Ready

```
[Name] bhai/sahab!

Aapne sahi kaha — website se business zaroor grow karta hai.

Kya hum aaj confirm kar sakte hain? Main immediately shuru kar sakta hun.

Process simple hai:
1️⃣ 50% advance (PKR [Amount])
2️⃣ Main kaam shuru karta hun
3️⃣ Draft ready hone pe review
4️⃣ Final changes
5️⃣ 50% remaining + launch!

Advance JazzCash/EasyPaisa/Bank Transfer — jo convenient ho.

Ready hain? 🚀
```

---

### 🎯 Handling Price Objection

```
[Name] bhai, samajh sakta hun!

Budget concern bilkul valid hai.

Isliye main offer kar raha hun:

Option A: PKR [Full Amount] — Full payment, 10% discount
Option B: 3 installments — [Amount] x 3 months
Option C: Lite package — PKR [Lower Amount], basic website (upgrade baad mein ho sakta hai)

Aapke liye kaunsa theek rahega?

Kaam ki quality se koi compromise nahi — sirf payment flexible kar raha hun!
```
